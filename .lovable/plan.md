# ربط كل شعبة بجهة إرسال واتساب

## ملاحظة مهمة قبل البدء

واتساب Cloud API الرسمي من Meta **لا يدعم إرسال رسائل إلى مجموعات** — يرسل فقط إلى أرقام أفراد. لا يوجد استثناء لهذا، وأي حل يدّعي غير ذلك يستخدم أدوات غير رسمية معرّضة لحظر الرقم.

لذلك الخطة تعتمد نموذجًا هجينًا لكل شعبة، وأنت تختار الوضع لكل شعبة:

1. **إرسال تلقائي (Cloud API)** — تخزين رقم/أرقام مستلم لكل شعبة (مثل مسؤول الشعبة أو مندوب أولياء الأمور). الضغط على "إرسال إلى مجموعة الشعبة" يرسل التقرير فعليًا وتلقائيًا بدون فتح واتساب.
2. **مجموعة واتساب (نصف تلقائي)** — تخزين رابط المجموعة لكل شعبة. الزر ينسخ نص التقرير للحافظة ويفتح المجموعة مباشرة لتلصقها بضغطة واحدة.

كل شعبة يمكن أن تستخدم الوضعين معًا أو أحدهما.

## ما سيتم بناؤه

### 1. إعدادات الشعبة (تبويب جديد داخل الإعدادات)
جدول لكل شعبة يعرض: الصف، الشعبة، رقم/أرقام الإرسال، رابط المجموعة، حالة التنشيط. مع تعديل سريع لكل صف.

### 2. زر "إرسال إلى مجموعة الشعبة" داخل قائمة التصدير الحالية
يظهر في كل الأماكن التي فيها تصدير مرتبط بشعبة:
- الحضور (اليومي للشعبة)
- الواجبات (سجل الواجب)
- الحصاد العلمي
- العلامات (الملخص الأسبوعي)
- التقارير/الترتيب (ترتيب الشعبة)

سلوك الزر حسب إعداد الشعبة:
- إذا كان فيها أرقام Cloud API → إرسال فوري + إشعار نجاح/فشل.
- إذا كان فيها رابط مجموعة فقط → نسخ النص وفتح المجموعة.
- إذا لم تُضبط الشعبة → رسالة توجّه المستخدم إلى الإعدادات.

### 3. سجل الإرسال
صفحة/جدول يعرض آخر عمليات الإرسال (الشعبة، نوع التقرير، الوقت، الحالة، رسالة الخطأ إن وُجدت) لتتمكن من التأكد أن الرسالة وصلت.

## ما تحتاج تجهيزه من جهتك (لوضع Cloud API)

من حساب Meta for Developers:
- Phone Number ID
- Permanent Access Token
- قالب رسالة (Template) معتمد يحتوي متغيّرًا نصيًا واحدًا للتقرير — Meta تسمح بالرسائل الحرة فقط داخل نافذة 24 ساعة من رد المستلم، لذا القالب ضروري للإرسال المبدئي.

سأطلب هذه القيم بشكل آمن في الخطوة التنفيذية.

## تفاصيل تقنية

- ترحيل قاعدة بيانات: جدول `section_whatsapp_targets` (section_id، phone_numbers نصية مصفوفة، group_link، mode، is_active) + جدول `whatsapp_send_logs` (section_id، report_type، status، error، payload_preview، created_by). GRANT + RLS: القراءة/الكتابة للأدوار المصرح لها فقط (admin وreception/teacher حسب النمط الحالي).
- الإرسال عبر `createServerFn` جديدة في `src/lib/whatsapp.functions.ts` مع `requireSupabaseAuth`، تقرأ التوكن من `process.env` داخل الـ handler وتستدعي Graph API، ثم تكتب سجل الإرسال. التوكن لا يظهر أبدًا في الواجهة.
- تقسيم النص الطويل إلى رسائل متعددة بترقيم (1/3، 2/3...) لأن حد الرسالة 4096 حرفًا.
- إعادة استخدام `ExportTextDoc` و`buildReportText` الحاليين في `src/lib/report-text.ts` لبناء النص، وإضافة خيار "إرسال إلى مجموعة الشعبة" داخل `src/components/ExportMenu.tsx` عبر prop اختياري `sectionId`.
